## 1. Summary

This Meta BEP lists the BEPs formally Scheduled for Inclusion in the Jenner network upgrade.

## 2. Specification

The Jenner network upgrade comprises a total of 4 BSC only BEPs.

### BEPs Scheduled for Inclusion

#### BEPs need hard fork

* [BEP-702](./BEP-702.md) : Compliant Asset Standard on BNB Smart Chain
  * The hard fork makes the standard's code present on every node; token creation on a given network is then opened by the governance-appointed activation switch defined in the BEP, so availability can follow each network's own rollout schedule.
* [BEP-703](./BEP-703.md) : Payment Lane on BNB Smart Chain
* [BEP-706](./BEP-706.md) : Millisecond-Precision Block Timestamp Precompile
* [BEP-714](./BEP-714.md) : Reduce Initial Backoff Time to 1 Second

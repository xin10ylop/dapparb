## Schemas

### sources.csv

| Column | Meaning |
|---|---|
| slug | identifier; also the file stem in `texts/` and `raw/` |
| url | URL fetched (arXiv: abs URL of the version fetched) |
| title | title as stated (arXiv `citation_title`; HTML `og:title`/`<title>`; Discourse topic title; for text/markdown files the document's own heading, set in `collect/sources.json`) |
| authors_or_org | arXiv `citation_author` list; HTML meta author; otherwise the publishing organisation (set in `collect/sources.json`); for Discourse the opening-post author and the post that holds the cited text |
| publication_date_if_stated | arXiv: v1 date and full submission history; HTML: `article:published_time`/JSON-LD `datePublished` if present; Discourse: topic/post creation time; a date taken from the page body is marked "stated in page body"; empty otherwise |
| fetched_at_utc | time the fetch of that source finished (UTC) |
| access_notes | HTTP outcome, redirects, versions, pages; plus the collector's note on why the source was collected |
| question_lines | space-separated keys (table above) |
| kind | arxiv, html, discourse, pdf, text, json (json: body saved unchanged, used as its own text) |
| text_files | extracted text file(s) |
| raw_files | raw HTTP bodies (gzip) |
| status | `ok` or `failed: <reason>` |

### excerpts.jsonl

| Field | Meaning |
|---|---|
| slug | source slug |
| question_line | key |
| quote | exact substring of `text_file` (original line breaks kept) |
| location | section / table / page as labelled in the source |
| text_file | the text file the quote was taken from |
| char_start, char_end | Python character offsets of the quote in the decompressed text file (`text[char_start:char_end] == quote`) |

Built by `collect/build_excerpts.py` from `collect/excerpt-specs.jsonl`; a spec gives the passage (or its first and last words, or `abstract: true`)
and the matcher locates it with whitespace and typographic-quote tolerance, then writes the exact original substring. `abstract: true` takes the
arXiv abstract as printed on the abs page (copied into the text header). Unlocated specs go to `collect/excerpt-failures.jsonl` (empty at generation time
unless listed under Coverage limits).

### texts/*.txt.gz

- arXiv `<slug>.txt.gz`: header (arXiv id and version, title, authors, submission history, comments, abstract from the abs page), then
  `=== full text (arxiv.org/html, LaTeXML) ===` with the HTML full text converted to text: MathML replaced by its LaTeX `alttext`, table rows as
  cells joined by ` | `, footnote marks appear inline (e.g. `1515` = footnote 15), figures are captions only. If arXiv has no HTML version, the text is the PDF text.
- arXiv `<slug>.pdf.txt.gz`: same header + PyMuPDF text of the PDF with `=== page N ===` markers (for page citations). Not proof-read.
- html: `Source URL`, `Final URL`, `Page title` header, then the text of `<main>`/`<article>` if present (else `<body>`), then
  `=== hyperlinks in the extracted part of the page ... ===` (anchor text TAB href; derived).
- discourse: topic header, then the Discourse `/raw/<topic>` markdown of all posts; each post is headed `username | time | #n`.
- text: the response body unchanged (markdown, SQL, llms.txt).

### raw/

`<slug>.<part>.<ext>.gz` = gzip of the HTTP response body. Parts: `abs` (arXiv abs page), `html-vN`, `pdf-vN`, `page`, `topic` (Discourse JSON),
`raw` (Discourse markdown), `body`, `doc`. sha256 of every response body is in `collect/fetch-log.jsonl`.

### defillama/

`overview-dexs-<chain>.json.gz` = gunzip gives the exact body of `https://api.llama.fi/overview/dexs/<chain>?excludeTotalDataChart=false&excludeTotalDataChartBreakdown=false`
(chains: base, arbitrum, optimism, unichain, ethereum, polygon, bsc, solana). `summary-dexs-<protocol>.json.gz` = body of
`https://api.llama.fi/summary/dexs/<protocol>` (uniswap-v4, uniswap-v2, uniswap-v3, and the parent `uniswap`). Top-level keys include
`totalDataChart` ([unix_day_utc, usd_volume]), `totalDataChartBreakdown` ([unix_day_utc, {protocol: usd_volume}]), `total24h`, `total7d`, `total30d`,
`protocols` (overview) or `chainBreakdown` (summary). Daily points end at unix 1790726400 = 2026-09-30T00:00Z. `index.csv`: file, url, http_status,
bytes, sha256 (of the uncompressed body), fetched_at_utc.

## Reproduce

```bash
cd research-material/08-sources/collect
export REQUESTS_CA_BUNDLE=/root/.ccr/ca-bundle.crt SSL_CERT_FILE=/root/.ccr/ca-bundle.crt   # only behind the proxy
python3 fetch_sources.py            # fetch every entry of sources.json not yet fetched (checkpoint: fetch-state.json); --force refetches all, --only SLUG...
python3 fetch_defillama.py          # raw DefiLlama JSON into ../defillama/ (resumable; --force)
python3 build_excerpts.py           # ../excerpts.jsonl from excerpt-specs.jsonl (fails are listed, never silently dropped)
python3 make_searches_csv.py        # ../searches.csv from searches.jsonl
python3 make_manifest.py            # this file
```
Requirements: python3 with requests, beautifulsoup4, PyMuPDF (`fitz`). Requests are sequential per host with >= 1.5-3 s spacing;
HTTP 429/5xx are retried with backoff honouring Retry-After. Logs: `collect/fetch_sources*.log`, `collect/fetch_defillama.log`, `collect/fetch-log.jsonl`.

## Coverage limits and gaps

- Entropy Advisors: no standalone report was found. The figures quoted in docs/ANALYSIS.md 4.1 (share of atomic-arbitrage revenue retained: Arbitrum 1.74 %, Ethereum 28.83 % via MEV-Boost, Base 7.34 % via priority fees) appear in a forum post by the account "Entropy" (Entropy Advisors), post #7 (2026-06-16) in the Arbitrum forum thread on replacing Timeboost with PGA, which describes them as "research on revenue capture specifically (conducted in March 2026)". The underlying dataset/report behind that post was not located (queries in searches.csv; the Entropy monthly updates for Feb-Jun 2026 and the dashboards catalog were checked by text search). The dashboards catalog post is saved; the Dune dashboards themselves were not fetched (client-side rendered, need an API key).
- docs.base.org: the Base docs do not publish an "atomic-arbitrage revenue share"; the saved Base pages are the ordering / Flashblocks / fee / Denim / Jovian pages. Old URLs /base-chain/network-information/transaction-ordering, /block-building and /base-chain/flashblocks/faq redirect to the saved pages (recorded in collect/fetch-log.jsonl). https://docs.base.org/get-started/launch-token now redirects to an unrelated B20 asset-token page and was dropped. The Base tweet on the minimum-base-fee increase cited by arXiv 2606.00720 [7] (x.com) was not fetched: x.com needs a login.
- arXiv 2509.22143 (Messias & Torres): both v2 (current, 2026-07-21) and v1 (2025-09-26) are saved. The text states totals (Table 3), per-arbitrage means and the MEV-data period (2025-04-17 to 2025-07-31); neither version states a per-day arbitrage profit figure (text search of the HTML and PDF texts for "per day", "a day", "/day", "4.7K", "4,7": the only hits are other numbers such as 14,796,548; "daily" occurs only for transaction counts). The per-day figure in the question line therefore has no verbatim excerpt; the totals, period and per-arbitrage means are excerpted.
- Scope of the Q7 figures as stated in the sources: arXiv 2607.24172 (Pahari, Messias, Torres) states the 82 % -> 28 % profitable-bot figure for Base over 2023-09-01 to 2025-07-31, for speculative, non-speculative and hybrid arbitrage and liquidation bots (Table 6); arXiv 2606.00720 (Wu & Oz) states 21,374,434 arbitrages by 4,365 bot addresses for 2025-06-01 to 2026-02-28. Each paper's data period and detection method are excerpted (Q7-CHAINWIDE-METHOD, Q7-PROFIT-28, Q7-BASE-21M).
- Detection coverage of the studies: arXiv 2606.00720 extends the method of arXiv 2506.14768, which reads swaps from Dune `dex.trades` and pool interactions from `dex.raw_pools`. The Dune Spellbook model files listing which DEX projects feed `dex.trades` on Base, Arbitrum, Optimism and BNB are saved as of fetch time (main branch; the commit hash could not be read: api.github.com answered HTTP 403 unauthenticated). The Spellbook history (which projects were included during each study window) was not collected.
- Text extraction: HTML and PDF are converted to text by collect/fetch_sources.py; formulas, tables and footnotes are flattened, figures are not captured (only captions). PDF text (texts/*.pdf.txt.gz) was not proof-read. The raw HTML/PDF bytes are kept in raw/ for re-extraction.
- developers.uniswap.org answered HTTP 429 (Retry-After 507 s, then 3600 s). The PoolManager and Hooks pages were fetched after waiting; the collector was then stopped and the Dynamic Fees and v2 Deployments pages were taken from the site's source files on GitHub (raw.githubusercontent.com/Uniswap/docs/main/content/protocols/..., kind text). The collector now caps Retry-After at 900 s.
- Discourse threads (Arbitrum forum, Flashbots collective) are saved as the /raw markdown of all posts; images embedded in posts are not saved.
- Sources fetched but dropped after reading because they did not relate to any question line: arXiv 2609.18975 (pump.fun pipeline coverage), arXiv 2512.00377 (memecoin fragility index), arXiv 2603.13830 (BSC rug-pull warning, 7 tokens), docs.base.org configuration reference, docs.base.org launch-token (redirect). They were removed from sources.json and from texts/ and raw/.
- Not collected: X/Twitter posts; Dune dashboards; paywalled or login-only reports; news articles and SEO blogs returned by searches (listed in searches.csv only); Telegram/Discord statements; the 0x report's underlying data (only the published post). No peer-reviewed or arXiv study specific to Clanker/Zora/Virtuals launch sniping on Base was found by the searches in searches.csv (launch-related sources saved are the platform docs, Wu & Oz Section 5.3, and Solana/cross-chain memecoin studies).
- Solana, BSC and other-L2 coverage in this folder is limited to published sources; on-chain data for those chains is in research-material/06-*.
- Date fields: several web pages state no publication date in their metadata (publication_date_if_stated left empty). Dates visible only in the page body were copied only for the 0x post and the Uniswap Foundation post (marked "stated in page body"); for other pages they remain in the text files.
- arXiv HTML artefact: in the LaTeXML HTML of arXiv 2509.22143v1, digit-group separators render as the word "true" (e.g. "11true613true936" for 11,613,936). Excerpts from v1 are therefore taken from the PDF text (texts/arxiv-2509.22143v1-...pdf.txt.gz); the HTML-derived v1 text is kept unchanged.
